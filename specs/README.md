# Specs

Este diretorio guarda as especificacoes que guiam mudancas de produto e API.

Para criar uma nova spec:

1. Copie `TEMPLATE.md`.
2. Renomeie para `YYYY-MM-DD-nome-da-feature.md`.
3. Preencha todas as secoes obrigatorias.
4. Rode `composer spec:check`.

O guia completo esta em `docs/spec-driven-development.md`.
